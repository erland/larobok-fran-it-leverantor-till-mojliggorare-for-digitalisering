# Terminologi – första arbetsversion

| Begrepp | Gemensam tolkning |
|---|---|
| Förmåga | Vad en organisation behöver kunna utföra eller säkerställa |
| Plattform | Teknisk och organisatorisk helhet som erbjuder återanvändbara tjänster |
| Plattformstjänst | Dokumenterat och förvaltat erbjudande för återkommande behov |
| Intern plattformsprodukt | Plattformstjänst som kontinuerligt förbättras med brukare, livscykel och ansvar |
| Självbetjäning | Godkända återkommande uppgifter kan utföras utan manuell central beställningskö |
| Generation 3 | Plattformsorienterad IT med standardiserade förvaltade erbjudanden |
| Generation 4 | Verksamhetsdriven digitalisering, genom säker AI-användning, automation och eget skapande |
| Vibe programming | AI-stödd skapande av applikationer genom instruktioner i naturligt språk, med riskanpassad granskning |
