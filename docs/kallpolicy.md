# Källpolicy

- **Nivå:** Hög. Primärkällor för standarder och teknikrekommendationer.
- **Tidskänsligt:** Verifiera daterade påståenden nära färdigställande/publicering.
- **Osäkerhet:** G4 är en framtidsinriktad analys, inte belagd standard för alla organisationer.
- **Källform:** Gemensamt källregister sist i boken, käll-ID K001 osv.
- **Rätt och regler:** Skilj lagkrav från allmän praxis, specificera tillämplighetsvillkor.
- **Fall:** Fiktiva organisationsexempel markeras som illustrationer.
- **Äldre underlag:** Bevaras originaltroget i `docs/kallmaterial`; ändras inte vid bokredigering.
- **Källkontroll:** Säkerställ faktisk källa innan citat eller faktapåstående förs in i manus.
